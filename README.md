# КЕНТОФОН — звонилка по ID

Регистрация по логину и паролю, ник, 6-значный ID, поиск друга по ID, контакты, голосовые и видеозвонки прямо в браузере (WebRTC). Работает на телефоне (Safari / Chrome), можно добавить на экран «Домой» как приложение.

## Как пользоваться
- Регаешься и получаешь свой ID (например `482 913`).
- Жмёшь «Позвать друга» и кидаешь ссылку. Друг открывает её, регается, и ты сразу у него в поиске, остаётся нажать «Добавить».
- Добавление работает в обе стороны: вы появляетесь друг у друга в контактах.
- Зелёная трубка — голосовой звонок, камера — видеозвонок. Во время звонка: микрофон, камера, смена камеры, сброс.
- Чтобы звонок дошёл, у друга должен быть открыт сайт (вкладка или иконка на экране «Домой»).

## Установка на российский VPS (одна команда)
Нужен VPS с **Ubuntu 24.04** (хватит самого дешёвого тарифа, 1 ГБ RAM).

Зайди на сервер (веб-консоль в панели хостинга или SSH) и выполни:
```
curl -fsSL https://raw.githubusercontent.com/mascarti/kentofon/main/install.sh | bash
```
Через пару минут скрипт напишет ссылку вида `https://123.45.67.89`, её и кидаешь Кенту.

Что ставится:
- **сервер звонков** (Node.js, systemd-сервис `kentofon`);
- **HTTPS** через Caddy: сертификат Let's Encrypt прямо на IP, домен не нужен;
- **свой TURN-сервер** (coturn): звонок проходит через любой мобильный интернет, весь трафик остаётся на твоём сервере.

Свой домен вместо IP: `curl ... | DOMAIN=call.mysite.ru bash` (у домена должна быть A-запись на IP сервера).

Если сертификат на IP не выдаётся, используй бесплатный домен от sslip.io:
`curl ... | DOMAIN=123-45-67-89.sslip.io bash` (подставь свой IP через дефисы).

Порты, которые должны быть открыты (если в панели хостинга включён файрвол): `80/tcp`, `443/tcp`, `3478/tcp+udp`, `49152-65535/udp`.

**Обновление:** запусти ту же команду ещё раз. Аккаунты и ключи сохранятся.

**Логи:** `journalctl -u kentofon -n 50`, `journalctl -u caddy -n 50`, `journalctl -u coturn -n 50`.

## Для разработки
```
npm install
npm run dev        # запуск из исходника
npm run build      # собрать dist/kentofon.js (сервер одним файлом, без node_modules)
```
http://localhost:3000. На localhost камера и микрофон работают без https.
Проверить звонок строго через TURN: открыть сайт с `?relay`.

Переменные окружения: `PORT`, `HOST`, `DATA_DIR`, `SECRET` (подпись токенов, обязательно постоянная), `TURN_HOST`, `TURN_PORT`, `TURN_SECRET` (свой coturn с `use-auth-secret`), либо `TURN_URL`/`TURN_USERNAME`/`TURN_CREDENTIAL` для стороннего TURN.
