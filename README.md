# КЕНТОФОН — звонилка по ID

Регистрация по логину и паролю, ник, 6-значный ID, поиск друга по ID, контакты, голосовые и видеозвонки прямо в браузере (WebRTC). Работает на телефоне (Safari / Chrome), можно добавить на экран «Домой» как приложение.

## Как это работает
- Регаешься → получаешь свой ID (например `482 913`).
- Жмёшь «Позвать друга» → кидаешь Кенту ссылку. Он открывает её, регается — и ты сразу у него в поиске, жмёт «Добавить».
- Добавление взаимное: вы оба появляетесь друг у друга в контактах.
- Зелёная трубка — голосовой звонок, камера — видеозвонок. Во время звонка: микрофон, камера, смена камеры, сброс.
- Чтобы звонок дошёл, у друга должен быть открыт сайт (вкладка или иконка на экране «Домой»).

## Запуск на Render (бесплатно)
1. Залей эту папку в репозиторий на GitHub.
2. render.com → войти через GitHub → **New → Web Service** → выбрать репозиторий.
3. Language: **Node**, Build Command: `npm install`, Start Command: `npm start`, Instance Type: **Free**.
4. В **Environment Variables** добавить `SECRET` = любая длинная случайная строка (обязательно, иначе после перезапуска всех разлогинит).
5. **Deploy** → через пару минут получишь ссылку вида `https://kentofon-xxxx.onrender.com`.

(Или **New → Blueprint** — там всё возьмётся из `render.yaml`, SECRET сгенерится сам.)

### Нюансы бесплатного Render
- Если 15 минут никто не заходил, сервер засыпает — первое открытие сайта может занять до минуты.
- Render стирает файлы при перезапуске. Поэтому аккаунт хранится ещё и в подписанном токене на телефоне: после перезапуска всё восстанавливается, как только человек откроет сайт. Единственное: войти по паролю с **нового** устройства получится, только после того как ты хоть раз открыл сайт со старого.
- Хочешь без этих нюансов — запусти на любом VPS: `npm install && SECRET=... npm start` (порт задаётся переменной `PORT`, база лежит в папке `data/`).

## Если звонок не соединяется
Иногда мобильный интернет не даёт соединиться напрямую (строгий NAT). Тогда нужен TURN-сервер (например, бесплатный план у Metered или свой coturn). Добавь переменные:
```
TURN_URL=turn:адрес:3478,turns:адрес:443
TURN_USERNAME=логин
TURN_CREDENTIAL=пароль
```

## Локально
```
npm install
npm start
```
Открыть http://localhost:3000 (на localhost камера и микрофон работают без https).
